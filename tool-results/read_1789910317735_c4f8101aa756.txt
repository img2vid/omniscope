     1→     1→# OMNISCOPE — Universal Client-Side File Viewer
     2→     2→
     3→     3→Project: A fully client-side (GitHub Pages–ready) universal file opener/viewer supporting 10,000+ format
     4→     4→identities (extensions ∪ MIME types ∪ binary signatures ∪ archive segments ∪ character encodings), built with
     5→     5→Next.js 16 (App Router, single `/` route, all logic client-side, zero server APIs).
     6→     6→
     7→     7→Owner: main orchestrator (Z.ai Code). Subagents contribute isolated modules with Task IDs.
     8→     8→
     9→     9→## Architecture Map
    10→    10→- `src/lib/types.ts` — core types (RawFormat, FormatRecord, DetectedFormat, ViewerProps, ViewerId, FormatCategory)
    11→    11→- `src/lib/utils.ts` — general helpers (sizes, hex, entropy, hashes, strings, encodings)
    12→    12→- `src/lib/binary.ts` — DataReader for binary parsing
    13→    13→- `src/lib/formats/signatures.ts` — magic-byte signature engine
    14→    14→- `src/lib/formats/database.ts` — core authored format DB (~400 records)
    15→    15→- `src/lib/formats/extra-formats.ts` — SUBAGENT 2-a: large authored expansion (2,500+ records)
    16→    16→- `src/lib/formats/mime-registry.ts` — SUBAGENT 2-a: IANA/vendor MIME registry (3,000+)
    17→    17→- `src/lib/formats/families.ts` — SUBAGENT 2-a: programmatic segment families (.000–.999, .r00–.r99 …)
    18→    18→- `src/lib/detect.ts` — detection pipeline (magic → CFB/OOXML sniff → extension → content)
    19→    19→- `src/components/viewers/viewer-ui.tsx` — shared viewer chrome kit (toolbar, buttons, cards)
    20→    20→- `src/components/viewers/*` — viewer components (core by orchestrator; suites by subagents 2-b/2-c/2-d)
    21→    21→- `src/components/omniscope/*` — app shell: landing, workspace, tabs, info panel, format explorer
    22→    22→- `src/app/page.tsx` — single route entry
    23→    23→
    24→    24→## Rules for subagents
    25→    25→- Only create NEW files in their assigned paths; never edit shared files.
    26→    26→- Viewer contract: `export default function XViewer({ file, arrayBuffer, detected, fileName }: ViewerProps)`.
    27→    27→- All components `'use client'`, graceful error handling, dark zinc + emerald/amber palette, no blue/indigo.
    28→    28→- Append work record at end of task using the template.
